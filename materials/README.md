## Interactive Notebooks

### 1. `01_extraction_and_compilation.ipynb`
This notebook implements the complete data ingestion and corpus construction pipeline:
* **Hindi Subtitle NLP:** Parses `.srt` subtitle tracks using `pysrt`, tokenizes Devanagari sentences using `indicnlp`, and extracts dependency parses with Stanza Universal Dependencies (`hi`).
* **Hindi Literary Prose:** Scrapes and processes classic short stories by Premchand and Phanishwar Nath Renu, separating dialogue turns from authorial narrative prose.
* **Telugu Pipeline:** Ingests YouTube Auto-ASR `.json3` subtitle files from three contemporary Telugu films and short stories by Gurajada Apparao from Telugu Wikisource.
* **Corpus Compilation:** Compiles multi-source data into standardized cross-register CSV files.

### 2. `02_cross_linguistic_analysis.ipynb`
This notebook performs statistical and visual analysis structured in the exact language order:
1. **Hindi** (Main 6-source corpus $N_{\text{clean}}=3,089$ + Held-out verification corpus $N_{\text{clean}}=1,063$)
2. **Assamese** ($N_{\text{clean}}=97$)
3. **Bengali** ($N=373$)
4. **Telugu** (Automated $N=759$ vs. Manual Verified $N=116$)
5. **Tamil** ($N_{\text{clean}}=106$)
6. **Cross-Linguistic Synthesis** (Master comparison across all 5 languages)

Each section generates contingency tables, runs $\chi^2$ tests of independence and Fisher's exact tests, fits multivariate binomial logistic regression models, and generates publication dashboards.
